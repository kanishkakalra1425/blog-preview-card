

# Blog Preview Card

A simple and responsive Blog Preview Card built using HTML and CSS. This project displays an article preview with a category label, publication date, title, description, and author information.

## 🔗 Live Demo

[View Live Project](https://clinquant-pie-38ccbf.netlify.app)

## 📸 Overview

The Blog Preview Card features a clean layout with a yellow background, a white card, rounded corners, and a subtle black box shadow.

## 🛠️ Built With

- **HTML5** – For structuring the webpage.
- **CSS3** – For styling, layout, Flexbox, and responsive typography.
- **Custom Fonts** – Figtree font family using local font files.
- **Flexbox** – For centering the card and aligning author information.

## ✨ Features

- Clean and minimal UI.
- Centered card layout using CSS Flexbox.
- Custom Figtree typography.
- Article illustration with rounded corners.
- Hover effect on the article title.
- Responsive font sizing using `clamp()`.
- Author avatar and publication details.
- Custom box shadow and border styling.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd blog-review-card
   ```

3. Open `index.html` in your browser.
